# Афиша мероприятий

## Описание проекта

«Афиша мероприятий» — веб-приложение, разработанное на Python с использованием фреймворка Django. Приложение предназначено для просмотра, поиска и анализа мероприятий.

Пользователь может просматривать активные мероприятия, узнавать информацию об авторах, категориях, стоимости и количестве участников. Также реализована страница статистики с возможностью сортировки мероприятий по количеству участников.

## Цель проекта

Цель проекта — разработать веб-приложение для работы с мероприятиями и закрепить навыки использования Django ORM, связей между моделями и оптимизации запросов к базе данных.

## Функциональные возможности

1. Просмотр списка активных мероприятий.
2. Поиск мероприятий по названию, описанию и категории.
3. Просмотр подробной информации о мероприятии.
4. Отображение автора, цены и категорий мероприятия.
5. Подсчёт количества участников и категорий.
6. Увеличение счётчика просмотров при открытии мероприятия.
7. Просмотр статистики мероприятий.
8. Сортировка мероприятий по количеству участников.
9. Управление мероприятиями и категориями через административную панель Django.

## Модели данных

### Category

Модель категории мероприятия содержит:
- название;
- описание;
- дату создания.

Название категории должно быть уникальным.

### Event

Модель мероприятия содержит:
- название;
- описание;
- автора;
- категории;
- участников;
- цену;
- максимальное количество участников;
- количество просмотров;
- статус активности;
- дату создания.

Автор связан с моделью пользователя Django через `ForeignKey`. Категории и участники связаны с мероприятием через `ManyToManyField`.

## Использование Django ORM

В проекте применяются следующие возможности Django ORM:

- `select_related()` — получение связанных данных автора.
- `prefetch_related()` — предварительная загрузка категорий и участников.
- `Q` — объединение условий поиска через логическое ИЛИ.
- `F` — увеличение количества просмотров непосредственно в базе данных.
- `annotate()` — добавление вычисляемых значений к объектам мероприятий.
- `Count()` — подсчёт участников и категорий.
- `distinct()` — исключение повторяющихся мероприятий из результатов поиска.
- `EventQuerySet` — собственные методы для работы с мероприятиями: `active()`, `popular()`, `with_details()` и `recent()`.

## Установка и запуск

### 1. Клонирование репозитория

Если проект размещён на GitHub:

```bash
git clone ССЫЛКА_НА_РЕПОЗИТОРИЙ
cd events_project
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
```

### 3. Активация виртуального окружения

Для macOS и Linux:

```bash
source venv/bin/activate
```

### 4. Установка Django

```bash
python -m pip install django
```

### 5. Применение миграций

```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. Заполнение тестовыми данными

```bash
python manage.py shell < events/populate.py
```

Скрипт создаёт категории, тестовых пользователей и мероприятия с различными ценами, статусами и участниками.

### 7. Создание администратора

```bash
python manage.py createsuperuser
```

### 8. Запуск сервера

```bash
python manage.py runserver
```

После запуска приложение доступно по адресу:

http://127.0.0.1:8000/

Административная панель:

http://127.0.0.1:8000/admin/

Статистика мероприятий:

http://127.0.0.1:8000/statistics/

## База данных

По умолчанию используется SQLite. Файл базы данных называется `db.sqlite3`.

При выполнении миграций Django создаёт необходимые таблицы. Тестовые данные можно добавить с помощью скрипта `events/populate.py`.
